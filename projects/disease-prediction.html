01

Overview

The project treats performance in a development dataset as the beginning of model evaluation, not the end.

It was designed to examine model reliability under cross-site change, with particular attention to reproducible evaluation, uncertainty, calibration and transparent limitations. This page intentionally provides only a high-level portfolio summary while permission for public release is pending.

02

Capabilities demonstrated

Evaluation design

Structured development and external-evaluation stages to reduce optimistic performance claims.

Reproducible analysis

Built a documented Python workflow with controlled inputs, repeatable outputs and validation checks.

Reliability assessment

Considered discrimination, probability quality, uncertainty and sensitivity rather than relying on one headline metric.

Responsible reporting

Separated evidence from interpretation and documented intended-use boundaries and limitations.

Release plan

Citable archive

05

Responsible use

This academic project is a methodological evaluation, not a clinical product.

It is not intended for diagnosis, treatment decisions or deployment in healthcare. Any later public version will retain clear limitations, provenance, citation information and an explicit intended-use statement.
