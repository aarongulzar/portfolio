Disease Prediction using Machine Learning

An in-progress machine-learning project exploring disease prediction with careful evaluation.

Project overview

This project is currently in progress. It is intended to explore machine-learning approaches for disease prediction while keeping model claims cautious and evidence-based.

Planned focus areas

  • Data cleaning and preparation.
  • Feature selection and model comparison.
  • Evaluation using appropriate classification metrics.
  • Clear discussion of limitations and responsible interpretation.
