Information Retrieval with BM25

A project focused on BM25 ranking and core information retrieval techniques.

Project overview

This project explores information retrieval using BM25, a ranking function commonly used to score how relevant documents are to a search query.

Focus areas

  • Text preprocessing for search-style tasks.
  • Query handling and document scoring.
  • Understanding how BM25 balances term frequency and document length.
  • Presenting retrieval results clearly without overstating performance.
