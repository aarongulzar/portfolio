Deep Learning for Image Classification

A custom CIFAR-10 convolutional network and a controlled Fashion-MNIST ablation study, built and evaluated with PyTorch.

The project explores input-conditioned convolutional blocks, model regularisation and the practical trade-offs between batch normalisation, dropout and data augmentation.

View GitHub Repository View Coursework Report

Project Overview

Two datasets, one investigation into better generalisation.

This university coursework project combines architecture design on CIFAR-10 with a systematic regularisation study on Fashion-MNIST.

For CIFAR-10, I implemented a custom CNN whose intermediate blocks learn input-dependent weights for several parallel convolutional paths. I then improved the model by increasing its width and number of paths, adding data augmentation, and refining the optimisation strategy. The second part compares four Fashion-MNIST CNN variants under the same 10-epoch training budget to isolate the effects of batch normalisation, dropout and augmentation.

Architecture

An input-conditioned convolutional network.

Each intermediate block sends the same feature map through independent convolutional paths. A channel-wise spatial average and fully connected layer generate softmax-normalised coefficients, allowing the network to combine those paths differently for each input. Four blocks increase the channel depth while max-pooling progressively reduces spatial resolution from 32×32 to 4×4 before the final 10-class output.

Training Results

Thirty epochs of CIFAR-10 training.

The improved model used random cropping, horizontal flipping, cross-entropy loss, AdamW, weight decay and cosine-annealing learning-rate scheduling. Loss declined while training accuracy rose above 94% and test accuracy peaked at 87.81%. The widening train-test gap also revealed some overfitting toward the end of training.

Fashion-MNIST Ablation Study

Isolating the impact of regularisation choices.

Four CNN variants shared the same training protocol: a baseline, a model with batch normalisation and dropout, a no-dropout version, and an augmented version using random cropping and horizontal flipping. Batch normalisation with dropout performed best at 92.50%. Removing dropout pushed training accuracy to 98.82%, but its best test result was 92.05%—a clear sign of increased overfitting. Augmentation reached 92.00% within the fixed 10-epoch budget.

Challenges

Designing a fair experiment while managing overfitting.

Custom block implementation

Keeping tensor dimensions aligned across parallel paths and combining them with input-dependent weights.

Generalisation

Improving test performance while the training curves showed a growing tendency to overfit.

Controlled comparisons

Holding the Fashion-MNIST training budget constant so each architectural change could be interpreted clearly.

Evaluation limits

Recognising that repeated test-set evaluation and single runs limit how confidently results can be generalised.

What I Learned

Strong results need careful experimental design.

  • How to translate a custom CNN design into reusable PyTorch modules.
  • Why training and test curves must be read together when diagnosing overfitting.
  • How batch normalisation, dropout and augmentation affect optimisation and generalisation differently.
  • Why a validation split, repeated seeds and summary statistics are essential for more reliable model selection.
  • How to document experiments so architecture choices and limitations remain transparent.
