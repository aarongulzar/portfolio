# Aaron Gulzar Portfolio

A modern, responsive personal portfolio for Aaron Gulzar, focused on machine learning, data science, artificial intelligence, and software development.

## Highlights

- React component structure with reusable cards, sections, navigation, and theme controls
- Clean Apple/Stripe/Linear-inspired visual system
- Responsive layout for mobile, tablet, and desktop
- Dark/light mode with saved user preference
- Subtle motion with reduced-motion support
- CV download, GitHub, LinkedIn, and contact sections

## Local development

Install dependencies with pnpm, then run the development server:

```bash
pnpm install
pnpm dev
```

Build for production:

```bash
pnpm build
```
